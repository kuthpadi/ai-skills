# AI Skills Repository

A curated library of reusable AI skills, playbooks, and reasoning frameworks for solving problems, making decisions, and accelerating execution across domains.

## Purpose

This repository contains reusable skills that can be used across AI assistants, agents, copilots, and workflow automation systems.

The goal is to capture proven reasoning patterns, review methodologies, and decision-making frameworks in a reusable format.

## Repository Structure

```text
skills/
```

Contains individual skills.

Each skill is self-contained and includes:

* skill definition
* examples
* anti-patterns
* version history

## Versioning Philosophy

Skills evolve through real-world usage.

Changes should be:

* incremental
* documented
* backward compatible where possible

Refer to each skill's CHANGELOG.md for version history and enhancements.
